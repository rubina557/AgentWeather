# AgentWeather

## Agentic Multi-Metric Weather & AQI Forecasting System

AgentWeather is an AI-powered weather and air-quality forecasting system that predicts six environmental metrics for the next 24 hours and uses an agentic reasoning layer to generate alerts, weather reports, and monitor forecasting performance.

## Project Objectives

- Forecast Air Quality Index (AQI).
- Forecast temperature.
- Forecast precipitation and rain probability.
- Forecast humidity.
- Forecast UV Index.
- Forecast wind speed and direction.
- Evaluate and compare forecasting models.
- Generate hazard alerts and weather reports using AI agents.
- Detect data drift and model drift.
- Deploy an interactive dashboard.
